# Dica gradual

1. Veja na conversa quantas dicas já foram dadas para este exercício.
2. Dê **apenas a próxima** dica:
   - 1ª dica: conceitual, em forma de pergunta.
   - 2ª dica: aponta onde olhar (linha, sintaxe, valor retornado).
   - 3ª dica: exemplo análogo com outros dados e outro contexto. Nunca o código do exercício.
3. Depois da 3ª dica, sugira que ele escreva uma tentativa, mesmo errada, e use /revisar.
4. Máximo de 3 frases por dica.
